## 1. 진입 퍼널 · 내비게이션 아키텍처 (Phase 1–5)

- **포탈**: 루트 리다이렉트 → 세로 3분할 hover 관문. 클릭 시 `sm_domain` 쿠키 주입, 미로그인 시 `/login?next=<도메인홈>` 게이트(`src/lib/domain.ts` 계약).
- **3단 내비 매트릭스**: GNB = 현재 도메인 세부 종목 탭(동적), LNB = 고정 5대 메뉴(대시보드/모의고사/훈련방/오답/플래너), 우측 = 활성 메뉴 구독형 동적 가이드. 몰입형 시험방은 셸 미적용.
- **레거시 폐기**: 통합 대시보드(`/student/dashboard`)·구언어 대시보드(`/student/language`) 삭제, 7개 끊긴 링크를 포탈/도메인홈으로 리포인팅, 에세이 플로우 `/student/lang` 일원화.
- **도메인 격리 하드 가드**: 플래너·오답 보관함을 `sm_domain` 스코프로 쿼리(타 도메인 혼입 차단). 페이스메이커 배너를 도메인 대시보드로 포팅(활성 카테고리 스코프).

## 개발 내용 평가

### 잘 된 점
- **응집된 10단계 아키텍처 전환**을 무중단·0에러로 완주. 포탈→도메인 격리→BM(마이페이지/Q&A)→실시간→AI 엔진→무한 콘텐츠 공급망으로 일관된 서사.
- 파괴적 변경(레거시 폐기)·운영 DB 쓰기를 **승인 게이트 + 멱등**으로 안전 처리, 고아 코드 정리(`DashboardLayout`/`LanguageDashboard`/`CurriculumExplorer`).
- 도메인 격리·RLS 준수·키 비노출 등 보안 기본기 유지.

### 리스크 · 기술부채 (정직한 평가)
1. **AI 실연동 미검증** — `OPENAI_API_KEY`/`SOLAR_API_KEY` 운영 설정 여부 불명(2주차에 `AI_API_KEY` 401 이력). 현재 essay/analyze/generate는 폴백·mock 경로일 가능성. → `/api/ai/health`(강사)로 우선 확인 필요.
2. **온디맨드 mock 영속화** — 키 부재 시 표본 문항이 DB에 적재되어 콘텐츠 품질 오염 가능. 키 설정 후 재생성 또는 mock 비영속화 정책 필요.
3. **스트림 라벨 불일치** — config(내신/수능/IB/AP) vs 012 백필(내신/수능 통합) → 기존 수학 단원이 신규 트리와 분리. 통계 필터는 근사.
4. **튜터 배정 의존** — Q&A는 `tutor_students` 매핑 존재 시에만 동작. 미배정 질문 클레임/배정 UI 부재.
5. **관리자 통계 권한** — 별도 admin 역할 없어 모든 tutor가 전역 통계 열람.
6. **어학 오디오 미완** — 녹음은 webm(스펙 wav/mp3와 차이), 스피킹 채점 라우트·리스닝 음원 데이터 부재.
7. **자동화 테스트 전무** — 검증이 빌드/타입체크 + 수동에 의존. 필터 캐스케이딩·생성 파싱·통계 집계 단위 테스트 없음.
8. **진단 page `select('*')` answer 클라 노출**(2주차부터 미해결) — 보안 정비 필요.
9. **AI 출력 검증 부재** — 생성 문항의 정답 정합성·유해성 검증 없음(형태 검증만).
10. **Vercel 환경 의존** — service role·AI 키·OAuth 리다이렉트 미설정 시 기능 무성/저하.
